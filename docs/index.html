CForge

CForge language and backend specification

A low-level backend DSL and systems-language experiment: small typed language → C11 (plus experimental x86-64 ELF), with a bounded-memory HTTP/TLS/SQLite runtime on Linux. Not a general-purpose Rust/C competitor in 0.1.

Handlers live in .cforge files. HTTP, JSON, TLS, and storage live in the C runtime, not in the language grammar.
