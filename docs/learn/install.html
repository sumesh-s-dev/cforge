Installation

Requirements

ComponentServer pathMachine path
Python 3yes (compiler driver)yes
GCC or Clangyesno
pkg-config + libsqlite3yesno
OpenSSL dev libsyes (TLS)no
Linux x86-64yesyes

Clone and verify


git clone git@github.com:sumesh-s-dev/cforge.git
cd cforge
./cforge test

You should see ok 14 checks and machine ELF tests.

Build the users service


./cforge build
# → build/cforge-users

Optional: systemd deploy (localhost)


./cforge deploy
curl http://127.0.0.1:8080/health

TLS on https://127.0.0.1:8443 uses self-signed certs under deploy/ (created on first deploy).

Publish documentation locally


python3 docs/build_docs.py
# open docs/index.html in a browser

Public docs URL: https://sumesh-s-dev.github.io/cforge/ (deployed from the gh-pages branch on each push to main).

In GitHub: Settings → Pages → Source: Deploy from branch gh-pages / root (set once after the first successful Pages workflow).
