Environment variables

Read at process start by the runtime (app_listen).

VariableDefaultMeaning
PORT8080HTTP listen port when app_listen(0)
TLS_PORT8443TLS port if certs set
CFORGE_BIND127.0.0.1IPv4 bind address
CFORGE_DBdata/users.dbSQLite database path
CFORGE_TLS_CERTunsetPEM certificate path
CFORGE_TLS_KEYunsetPEM private key path
CFORGE_MAX_CONNS128Connection slab size (1–4096)
CFORGE_DB_POOL4SQLite connections in pool (1–8)

Parent directory of CFORGE_DB is created if missing.

systemd example

See deploy/cforge-users.service.example — replace __CFORGE_ROOT__ with clone path.

Security

Default bind is localhost. Use CFORGE_BIND=0.0.0.0 only with firewall rules and real TLS certificates.

Private keys are gitignored; generate with ./cforge deploy or OpenSSL.
