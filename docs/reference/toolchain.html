Toolchain commands

All commands run from the repository root via ./cforge.

CommandDescription
buildServer backend: .cforge → C → build/cforge-users
checkParse and emit build/users.gen.c without linking
runBuild and replace process with server binary
testIntegration tests (HTTP + TLS + machine ELF)
deployBuild, install systemd user unit, health check
statusGET /health and /metrics on port 8080
alltest + deploy + status + git publish script
packageWrite cforge.lock source fingerprints
machine <file> [-o path]Native ELF backend
machine-testVerify mach/add and mach/expr exit codes
